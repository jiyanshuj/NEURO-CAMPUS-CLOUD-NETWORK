```sql
- user_id (PRIMARY KEY)

- password_hash
- role (admin/teacher/student/guest)
- first_name
- last_name
- created_at
- last_login
- is_active
```

```sql
- student_id (PRIMARY KEY)
- user_id (FOREIGN KEY → users)
- enrollment_number (UNIQUE)
- roll_number
- department
- semester
- section
- academic_year
- admission_date
- current_cgpa
- contact_number
- parent_contact
- address
- date_of_birth
- blood_group
- face_encoding (BLOB)
- created_at
- updated_at
```

#### 3. **teachers** - Faculty Information
```sql
- teacher_id (PRIMARY KEY)
- user_id (FOREIGN KEY → users)
- employee_id (UNIQUE)
- department
- designation
- qualification
- specialization
- experience_years
- contact_number
- date_of_joining
- salary
- face_encoding (BLOB)
- created_at
- updated_at
```

#### 4. **subjects** - Courses & Classes
```sql
- subject_id (PRIMARY KEY)
- subject_code (UNIQUE)

- department
- semester
- credits

- description
- created_at
- updated_at
```

```sql
- academic_year
- semester
- created_at
```

```sql
- attendance_id (PRIMARY KEY)
```

```sql
- comment_id (PRIMARY KEY)
```

## 🚀 Getting Started

### Prerequisites

```bash
Node.js >= 18.x
Python >= 3.8
npm or yarn
pip
Git
```

### Installation

#### 1. Clone the Repository
```bash
git clone https://github.com/Yug-Bothra/NEURO_CAMPUS.git
cd NEURO_CAMPUS
```

#### 2. Frontend Setup

```bash
# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env with your credentials

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

#### 3. Backend Setup

```bash
# Navigate to backend directory
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your credentials

# Run server
python main.py

# Or with auto-reload
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### Environment Configuration

#### Frontend (.env)
```env
# Supabase Configuration
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

# Clerk Authentication (for Career Guidance)
VITE_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key

# Cloudinary Configuration
VITE_CLOUDINARY_CLOUD_NAME=your_cloud_name
VITE_CLOUDINARY_API_KEY=your_api_key

# API Endpoints
VITE_API_URL=http://localhost:8000

# Gemini AI
VITE_GEMINI_API_KEY=your_gemini_api_key
```

#### Backend (.env)
```env
# Google Gemini AI
GEMINI_API_KEY=your_gemini_api_key

# Supabase Configuration
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_service_role_key

# Cloudinary Configuration
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# Database
DATABASE_URL=your_postgresql_connection_string

# Security
SECRET_KEY=your_secret_key
JWT_SECRET=your_jwt_secret

# Server Configuration
HOST=0.0.0.0
PORT=8000
DEBUG=True
```

### Running Tests

```bash
# Frontend tests
npm run test
npm run test:coverage

# Backend tests
pytest
pytest --cov

# Specific test suite
npm run test -- --testNamePattern="Component Name"
```

### Deployment

#### Vercel Deployment (Frontend)
```bash
# Install Vercel CLI
npm install -g vercel

# Login to Vercel
vercel login

# Deploy
vercel --prod
```

#### Configuration Steps:
1. Connect GitHub repository to Vercel
2. Configure environment variables in Vercel dashboard
3. Enable automatic deployment on push
4. Set up custom domain (optional)
